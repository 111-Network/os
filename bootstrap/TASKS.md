## Pinned contracts (bind every task; additive-only after T0)

**Crate:** workspace at `os/bootstrap/`; single crate `crates/node111` (package `node111`, `[[bin]] name = "111"`). musl-static, x86_64 + aarch64 (`-C link-arg=-zmax-page-size=16384` on aarch64).

**Dependency policy:** only the deps scaffolded in T0's `Cargo.toml`; `Cargo.lock` committed; new deps require reviewer sign-off recorded in the task's status note. Approved set: tokio · axum · rust-embed · serde/serde_json · toml · sha2 · hmac · k256(schnorr) · bip39 · bech32 · scrypt · chacha20poly1305 · minisign-verify · ureq(rustls, no native-certs) · webpki-roots · sysinfo · os_info · nusb · rtnetlink · sd-notify · time · libc · anyhow · tempfile. Dev-only: tiny_http is NOT allowed — test servers use std `TcpListener` helpers in `tests/common/`.

**Module stubs** (created in T0, tasks fill them): `util/{fs,hash,http,run}` · `calver` · `manifest` · `minisign` · `floor` · `identity/{mod,bip32,nip49}` · `install/{mod,preflight,probe,categorize,packages,stage,supervise,verify,offer,receipt}` · `install/phone/{mod,adb,preflight,apk,runas,harden,start,verify,teardown}` · `daemon/{mod,supervise,watchdog,health,kb}` · `daemon/dashboard/{mod,routes}` · `daemon/transport/{mod,venv,config,netlink}` · `daemon/updater/{mod,fetch,stage}` · `update_helper` · `update_guard` · `probation` · `cli` · `config` · `uninstall`.

**Cross-module APIs** (frozen at T0; signatures may gain `&self`-style plumbing but not change semantics):
- `probe::collect(env: &dyn Env) -> Facts` · `categorize::categorize(f: &Facts) -> (Category, bool /*gateway*/)` — pure, no I/O outside injected env.
- `health::Components { identity: bool, kb: bool, transport: TransportHealth, updater_idle: bool }` · `health::evaluate(&Components) -> HealthStatus` (200 iff all green; transport green = `Alive | DeliberatelyAbsent`).
- `daemon::supervise::spawn_child(spec: ChildSpec) -> ChildHandle` — restart-in-place, exp backoff (250ms→cap 60s, ×2, ±20% jitter), crash-loop detector (≥5 restarts/60s ⇒ `Degraded`).
- `probation::{Journal { schema, pending, version, previous, deadline_epoch, health_confirmed }, read/write/verify}` — journal write precedes flip, always.
- `manifest::{ChannelManifest::parse+verify(minisig, pubkey)+check_floor(&Floor)}`, `floor::Floor { schema, highest_release, highest_manifest_date, highest_keychain_generation }`.

**On-disk schemas** (all JSON `{ "schema": 1, ... }`, additive-only):
- `state/update-request.json`: `{schema, version, manifest_sha256, staged_path, requested_at}` · `state/revert-request.json`: `{schema, reason, requested_at}`
- `state/update.json` (journal, root-written): `{schema, pending, version, previous, deadline_epoch, health_confirmed}`
- `state/floor.json` (root-written): `{schema, highest_release, highest_manifest_date, highest_keychain_generation}`
- `state/facts.json`: `{schema, facts: <Facts serde>, category, gateway, probed_at}`
- `state/offer.json`: `{schema, tier: "standard", state: "offered"|"accepted"|"dismissed", recorded_at}`
- `receipt.json` (root 0644): `{schema, version, installed_at, category, gateway, npub, cache_hashes: {relpath: sha256}, degrade_branches: [String], phone: null|{serial, model, sdk, oem, taps, bf_note}}` — untrusted on re-read.
- Payload tree manifest: `share/payload.manifest` inside the tarball, lines `sha256␠␠relpath`; verified on every extract/promote.

**HTTP contracts:**
- `GET /health` → always JSON `{schema:1, status:"ok"|"error", components:{identity:bool, kb:bool, transport:"alive"|"absent"|"degraded", updater_idle:bool}}`; 200 iff `ok`, else 503.
- `GET /api/status` → `{schema:1, node:{npub,category,version,uptime_sec}, kb:{sha256,entries}, transport_state:"no transport"|"isolated"|"joined"|"transport degraded", health:<health body>, updates:{last_successful_check:null|RFC3339, pending:bool, floor}, clock_fault:bool, offer:null|{tier,state}, error_state:null|{kind,detail}}`. Additive-only; this is the Layer 4/9 seam.
- Dashboard page + both endpoints: GET-only (405), Host allowlist `127.0.0.1`/`localhost` (any port), bind `127.0.0.1:11180` default, LAN bind only via `111 config dashboard.lan true` with printed warning. No identity material on any endpoint.

**Constants:** port 11180 · user `node111` · roots `/var/lib/111` `/etc/111` · symlink `/usr/local/bin/111` · unit names `111node.service` `111node-update.{path,service}` · calver `YYYY.MM.DD[.N]` (zero-padded, lexicographic) · min calver crate-compiled · rns lockfile `rns==1.5.6` hash-locked · Termux pins `termux-app v0.118.3` / `:Boot v0.8.1` / `:API v0.53.0`.
