`plan/layers/60-transport/review/` (`bridge.md`, `carriers.md`, `integration.md`, `triage.md`, `recheck.md`). Contract: `40-interface/api/openapi.yaml`
(additive). Tasks that share a file never run in parallel; the Files column is the ownership record. Rust in `10-bootstrap/crates/node111` is Layer 1's

the bridge core and the Meshtastic client, then LXMF, app peers and the device core, then verification. Owner-gated items are closed by D26.

`panel-lint.sh` together; Linux hygiene (`AGENTS.md`): nothing of ours stays running after a check.
