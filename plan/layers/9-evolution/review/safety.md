# Layer 9 spec v0.1 review: safety (authority, validation, undo)

**Verdict: amend-then-lock.** Three blockers, each closed by a paragraph of spec text; no redesign. Judged 2026-11-12 against `README.md` §9 and the
operating principles, D35, D36, the brief, R00-R07g3 and the code at `fa1daeb` (the draft's head; the tree's HEAD is `7b1225d`, 28 commits later).
Draft lines are `9-evolution/README.md:<line>`; `N/`, `NI/`, `A/`, `ID/`, `M/`, `API` as the draft defines them.

## Notes

- Good: the closed action enum with no command, URL or template; signing built only in `111d` with a tag per artefact and a length-prefixed input; the T1
  reply held to an enum and to substring quotes with no retry; peers' text kept away from the receiving agent; no key, token or `Signed-off-by:` on a device;
  the opencode self-approval path found in code and closed first in the sequence; `update.rollback` and component downloads cut back to what the code allows.
- No path found where code is applied, where a key reaches the agent, or where a wall clock orders or signs anything in Layer 9's own rules.
- The signature inputs are sound: neither tag is a prefix of the other or of a registered tag, and `body_len` removes the split ambiguity.
- The automatic undo is the layer's one autonomous act. S4, S5, S6 and S8 are all about it; build it first (§15 item 2) with the stale, second-restore and
  consent-gate cases as tests before any new action joins the vocabulary.
- Watch in the build: every new action needs a per-action round trip in G20 (apply, forced probe failure, state equal to before), and the engine should
  refuse an action whose undo record fails to re-read after the fsync.
- Watch in the build: `service.log` and `incident.read` put log text in front of the chat model, which can file `device` proposals. That is the same class as
  `messages.read` today; keep the untrusted block and add an injection case to the §13 suite.
- Loopback-is-human stays (Q10). After S1 and S2 the residual risk is a local process without a bearer; the deny block and G24 are the only guard, so G24
  should not be allowed to stay SKIPPED on the lock run.
- Not my lens, seen in passing: a T1 call on a node whose model sleeps (`--sleep-idle-seconds`) reloads it, which sits oddly beside "Layer 9 loads no model".
