## Accepted — blockers (5 unique, 5/5)

1. **adb revocation is unbuildable as written** (found 3×) → mitigation rewritten as the actually-scriptable `settings put global adb_enabled 0`, sequenced as the FINAL labeled point-of-no-return step (after verify + optional reboot test + OEM checklist), `--keep-adb` escape hatch, true revocation documented as a manual UI step; phone teardown (`111 uninstall --phone`) works over sshd post-lockdown.
2. **Auto-rollback has no surviving actor; crash-before-READY never reverts** (found 3×) → on-disk probation journal (`state/update.json`, written before the flip, absolute deadline); every daemon boot adopts probation and self-reverts (flip back + `reset-failed`) if READY+health aren't achieved by deadline — covers crash-before-READY, READY-but-503, and torn payloads (startup hash-check → flip to N-1).
3. **Self-update impossible under the spec's own sandbox** (found 3×: ProtectSystem=strict + root-owned /opt) → payload moved from `/opt/111` to node111-owned `/var/lib/111/releases/` (the brief's k3s-style fallback, promoted); **KB rides inside the release payload** (`releases/<ver>/share/kb/`), collapsing binary+KB pairing into one atomic symlink flip.
4. **Transport conditional broken on fresh Debian** (python3-venv absent; prefetch downloaded but never installed) → packages are now **installed** at install time (online guaranteed) AND cached for offline reinstall; rns wheel closure cached too; degrade branch recorded in receipt + dashboard.
5. **run-as-started node dies on adb disconnect** (no SIGHUP detach) → explicit `setsid nohup … </dev/null &` / detached-runsvdir start + unplug verification gate (V14).

## Rejected (with reason)

- **DoH to pinned endpoints** for Android DNS — adds pinned-endpoint fragility; hickory-resolver reading `getprop net.dns1` + IP-literal fallback is simpler and offline-consistent.
- **mDNS/Avahi discovery for the sshd maintenance channel** — multicast is exactly what's broken in Termux (MulticastLock finding); recovery = documented re-provisioning ceremony + Layer 9 watchdog channel instead.
- **Fork-update model (old binary parents the new one until healthy)** — probation-journal + boot-adoption solves the same actor-survival problem without a second process model; journal also covers torn-payload boot, which fork-update doesn't.
