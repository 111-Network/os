## Majors

| id | where | what | fix |
|---|---|---|---|
| S2 | §3.3 mdns-sd re-arm: "set 0 at start; a debounced address event re-arms one check by setting 1 s and, after it runs, 0 again" | `process_set_option` (`MD/service_daemon.rs:1705-1708`) schedules the next check at now + interval and `schedule_ip_check` (`:1844-1850`) re-arms it after every run while the interval is non-zero, so "1 s" is a 1 s poll (60 wakeups/min, worse than the 5 s default) until the daemon sets 0; setting 0 cancels a check that has not fired yet (`next_ip_check = None`). 111d gets no "it ran" signal, so the builder has to invent a sleep, and a set-0 that comes early freezes the record while one that never comes (task dropped) leaves the poll running on every LAN-sharing node. | Pin the procedure: on a debounced address event, `set_ip_check_interval(1)`, one `tokio::time::sleep(1500 ms)` (a one-shot, not an interval), then `set_ip_check_interval(0)`, inside one task that owns the mdns handle so two events serialise; G8 asserts `get_ip_check_interval()` reads 0 within 2 s of every event and the record's A records changed. ## Notes

- Good: every floor claim is labelled estimated or "measured at build"; nothing resident lands on a non-hub node; the phone-home hunt found none (the
  only recurring contact is the updater's check, user-off; the carrier endpoint is the owner's; the installer's probe stays one-time).
- Good: the rustls RFC 7250 facts hold line for line (`client_conn.rs:127`, `server_conn.rs:132`, `verify.rs:143`/`:272`, `webpki/verify.rs:213`,
  `ring/sign.rs:73`/`:393`); ureq enables exactly `logging`, `std`, `tls12` plus `ring` on rustls (`ureq-3.4.2/Cargo.toml:101-110`, `:194-203`), so a
  direct `rustls` dependency with default features off keeps `aws-lc-rs` out, as the draft says.
- Good: the libc group constants, the three 2 s ticks, the WAN loop, the netlink spine, `holds_custody`, the keepalive and back-off, the manifest
  parser's four trust gaps (T1–T3, T6) and the Layer 1 README lines are all cited to the line.
- Watch in the build: the mdns-sd re-arm (S2) is the one place a non-hub node could gain a poll; make G8's assertion the first test written.
- Watch: the member's hub-origin check on link-up is a new non-loopback `connect()` on a non-hub node (event-driven, allowed); keep it out of the
  G7 idle window by having no peer, as §3.7 already does, and count its bytes in §16 once measured.
- Watch: `check_once` at daemon start runs before any sleep (`updater/mod.rs:101-108`); `updates.check_internet = false` must gate that first run too.
- Watch: Termux's 15 min carrier poll is the only poll in the layer; keep it behind both `gateway.enabled` and a failed netlink bind.
