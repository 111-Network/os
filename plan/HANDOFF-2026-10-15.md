- **Prerequisites on the box:** Rust stable + `x86_64-unknown-linux-musl` and `aarch64-unknown-linux-musl` targets, musl

  (netns harnesses need user namespaces with veth), Google Chrome for panel-lint, no Go needed (meshmud is CI-built;
  stubs stand in). First command: `1-bootstrap/scripts/check.sh` to see where the tree really is.
- **Orchestration:** the lead runs the Workflow scripts under `plan/layers/5-messaging/runs/workflows/*.js` (moved there by the
  2026-10-15 plan restructure and renumbered by the 2026-10-18 folder renumbering; `plan/README.md` has the layout and
  both old→new move tables). Each script hard-codes `ROOT = '/home/kia/projects/111network/os'`
  and a `JOURNAL` path under the lead's `~/.claude/...`: change `ROOT` to the local checkout and point `JOURNAL` at the
  exported files under `plan/layers/5-messaging/runs/journals/` (same line format, `result.*` is all the prompts read).
- **Lessons that cost hours:** (1) never `SendMessage` an in-flight Workflow agent — it forks a second copy on the same
  files; (2) the resume cache is a hash chain over the `agent()` call sequence — to resume after a crash, DELETE finished
  calls from the script and add a RESUMPTION NOTICE to the unfinished ones ("your partial work is on disk, inventory, keep,
  finish"), put bounce-prone tasks LAST; (3) finished workflow agents are not resumable — spawn fresh ones; (4) every cargo
  invocation from a parallel agent needs a private `CARGO_TARGET_DIR`; (5) the three crashes all came ~1–2 h into runs
  with 3–5 agents compiling in parallel (load average ≈ 18 on this WSL2 box) — suspected memory pressure killing the
  Claude process. Run at most 2–3 build agents at once on a small box, or raise the WSL2 memory cap.
- **Models (Anthropic plan):** sonnet for build/docs/UI, opus for Rust, fable for review, haiku for tiny jobs.
- **Rules that bind (from `CLAUDE.md` + `plan/EXECUTION.md`):** commit in `os/` after every verified task; NEVER add
  Claude co-author/attribution lines; agents never commit; lead runs the check, reads the diff, bounces via fresh agents.
