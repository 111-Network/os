Scout: seams. Read-only pass, 2026-11-11, head `4b9e521`. No harness was run; nothing was built. This list was built from the READMEs' seam sections (`2-identity/README.md:306-322`, `3-intelligence/README.md:44-52`, `4-interface/README.md:36-60,545-720`, `4-interface/api/README.md`, `5-messaging/README.md:797-826`, `6-transport/README.md:130-160,846-880`, `7-relay/README.md:1272-1312`, `1-bootstrap/README.md:140-279`), the root README layer table, and the node111 code layout.

**Summary.** There are 86 seam rows below (counted with `grep -c '^| [LX][0-9]'`, minus the 14 planned rows; 3 of the 86 are cross-cutting `X:` rows), of which about 12 are stubs or partial (status S, P or B/S, mostly Layer 7 hub side) and the rest are built; the Layer 8/9 section adds 14 planned rows. Almost every cross-layer seam goes through **one binary**: `111d` (`1-bootstrap/crates/node111`) path-depends on `id111` (Layer 2) and `mesh111` (Layer 5) (`1-bootstrap/crates/node111/Cargo.toml:26,68`; `mesh111` itself depends on `id111`, `5-messaging/crates/mesh111/Cargo.toml:14`), embeds the Layer 4 UI (`RustEmbed` over `4-interface/ui/dist`, `daemon/dashboard/routes.rs:60`) and spawns three kinds of child (`supervise.rs:75 ChildSpec`): Layer 3 (`llama-server` :11181, `111-agent` :11182, `daemon/intelligence.rs:172,204`), Layer 6/1 transport (`rnsd`, `transport/mod.rs:180`) and Layer 5/6 sidecars (`meshmud` :11230, `meshtastic-presence`, `lxmf-sidecar`, `deltachat-rpc-server`, `madmail`, `simplex-chat`). `agent111` has **no** path dependency on any other crate (`3-intelligence/crates/agent111/Cargo.toml`): its only seams are env vars, files, and loopback HTTP, so a Layer 3 break is always visible as an HTTP answer or a file, never a compile error. The wide seam is the `/api/v1` contract (`4-interface/api/openapi.yaml`, 67 path keys, counted with `grep -c '^  /'`) which is **hand-mirrored** three times (openapi → `types.gen.ts`/`sse.gen.ts`/`contract.gen.ts`; openapi → Rust enums such as `KINDS: [&str; 9]`, `proposals.rs:104`, `ServiceId::COUNT = 9`, `services/mod.rs:96`; openapi → agent tool schemas) and pinned by "pin lists" (`4-interface/api/README.md`, per-layer "Pin list"). No `utoipa` exists yet, so openapi drift is a first-class seam. Layer 7's hub side (`relay/`, `carrier/`, `origin/`, `registry/`) is still T0 stubs (`relay/mod.rs:1`, `carrier/mod.rs:1`, `origin/mod.rs:1`, `registry/mod.rs:1`; `relay/netwatch.rs:1`), while its mesh111 side has landed (`Fabric::forward_take/forward_done/carrier_inbound`, `fabric.rs:1517-1535`). Layers 8 and 9 have no code; their seams are "planned" rows.
