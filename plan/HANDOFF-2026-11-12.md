## Box notes

- **The usage limit is the real ceiling.** Ten agents at once spent a five-hour window in under two hours, twice, and every agent in flight
  died with partial edits on disk. Run four or fewer, land rows as they return, prefer short rows. A killed row restarts with an
  `args.extra` note ("a previous attempt was cut off; its edits are in the tree; do NOT start over"); read-only judges are all-or-nothing.
- Workflow run ids resume only inside the session that made them: a new session re-runs the scripts (`args.only`, `args.extra`,
  `args.reviewOnly`, `args.root`, `stopAfter`; `spec.js`: `panelOnly`, `lenses`; `fix.js`: `from`, `skipRepin`, `recheckOnly`).
- Cargo: private warm target dirs under the session scratchpad (`CARGO_INCREMENTAL=0 CARGO_BUILD_JOBS=2`, `TMPDIR` unset); at most two
  cargo builds at once; `smoke.sh` and `panel-lint.sh` never together; the `forward` suite takes 3–6 minutes under load.
- A builder may write `git show HEAD:<file>` over its files for a baseline and restore from a private copy: never move the branch under a
  running builder without patching its copy too.
- A fresh container needs: `pnpm install --frozen-lockfile` in `4-interface/ui`; `apt-get update && apt-get install shellcheck minisign
  iproute2`; `git config core.hooksPath hooks`; `cargo fetch --locked` in `3-intelligence` before `gen-notices.py`.
- Hygiene: nothing of ours runs or listens between steps; scratch only under the session scratchpad.
